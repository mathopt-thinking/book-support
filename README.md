# 実務で使える数理最適化の考え方（サポートページ）
**基礎から学ぶモデリング**

<div style="display: flex; align-items: center;">
  <img src="https://www.ohmsha.co.jp/Portals/0/images/noimage.png" alt="書影" style="width:300px; margin-right:10px;">
  <div style="display: flex; flex-direction: column;">
    <p>
    本書は、数理最適化の基礎から実務に応用する際のポイントや注意点まで、<span style="background-color: yellow;">「モデリング」の観点を中心にして</span>初学者にもわかりやすく解説します。
    モデリングには、「教科書的な問題」と「現実の問題」の間に大きな壁があります。
    本書は、数理最適化の実応用に日々取り組んでいる著者たちが、その経験をもとに、<span style="background-color: pink;">「数理最適化を使う際にどのようなことを気にするか」「どのように問題を捉えるか」などを、「<strong>数理最適化の考え方</strong>」としてまとめた</span>ものです。
    典型的な例題を、条件を変えながら深く考察しているので、様々に応用できるモデリングの考え方が身につきます。
    </p>
    <p>
    本書の「考え方」を習得することで、現実の問題を数理最適化を使って解決できるようになります。
    また、<span style="background-color: yellow;">モデリングスキルだけでなく、実際に数理最適化を応用する際のノウハウ</span>についても学べる点が特徴です。
    数学的な予備知識はなるべく仮定せず、必要となる概念は本を読み進める中で自然に身につくようになっています。
    </p>
    👍このような方におすすめ
    <ul>
      <li>数理最適化を実務で扱うビジネスマン、技術者、データサイエンティスト</li>
      <li>数理最適化を勉強する情報・経済・経営系などの学生</li>
      <li>数理最適化の応用を研究している研究者</li>
    </ul>
  </div>
</div>
