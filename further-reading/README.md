# 書籍案内

本ページでは，『実務で使える数理最適化の考え方』と関連する書籍を紹介します．
数理最適化の基礎から応用まで，さらなる学びに役立つ書籍情報です．

## 数理最適化の理論とアルゴリズムについて

- 梅谷俊治『[しっかり学ぶ数理最適化　モデルからアルゴリズムまで](https://www.kspub.co.jp/book/detail/5212707.html)』講談社サイエンティフィク (2020)

線形計画問題，非線形計画問題，整数計画問題などの代表的な最適化問題に対する基本的なアルゴリズムを一通り学ぶことができる入門書です．
理論的な側面だけでなく，現実の問題への応用も意識されています．

- 福島雅夫, 山下信雄『[数理計画入門　最適化の数理モデルとアルゴリズム（第3版）](https://www.asakura.co.jp/detail.php?book_code=28006)』朝倉書店 (2024)

初版は 1996 年．
以来ロングセラーとなり，限られた紙幅で数理最適化の主要なトピックを手際よく丁寧に解説する，定評ある入門書です．

- 矢部 博『[工学基礎　最適化とその応用（第2版）](https://www.saiensu.co.jp/search/?isbn=978-4-86481-111-8&y=2024)』数理工学社 (2024)

数理最適化の基本的な事項がコンパクトにまとめられています．
整数計画問題についてはあまり触れられていませんが，線形計画問題や非線形計画問題について詳しく扱われています．

- 今野浩, 鈴木久敏（編）『[整数計画法と組合せ最適化（ORライブラリー7）](https://ndlsearch.ndl.go.jp/books/R100000002-I000004323820)』日科技連出版社 (1982)

整数線形計画（ILP）とそれに関連する組合せ問題について，実用的解法を理論的考察とともに詳説しています．
分枝限定法から，より高度な話題であるベンダーズ分解まで，幅広い話題を扱っています．

- マイケル・コッヘンダーファー, ティム・ウィーラー（著）, 岸本祥吾, 島田直樹, 清水翔司, 田中大毅, 原田耕平, 松岡勇気（訳）『[最適化アルゴリズム](https://www.kyoritsu-pub.co.jp/book/b10024250.html)』共立出版 (2022)

数理最適化に関する様々なアルゴリズムが，豊富な図とプログラミング言語 Julia による実装例と併せて解説されています．
理論的な詳細よりも，それぞれのアルゴリズムのアイデアに焦点が置かれています．

- 久保幹雄, 田村明久, 松井知己（編）『[応用数理計画ハンドブック（普及版）](https://www.asakura.co.jp/detail.php?book_code=27021)』朝倉書店 (2002)

数理最適化の理論や応用について，ハンドブックという形でまとめられています．
各項目がそれぞれコンパクトに整理されているため，辞書として利用することができます．

## 数理最適化モデリングについて

- H.P.ウイリアムス, 小林英三（訳）『[数理計画モデルの作成法](https://ndlsearch.ndl.go.jp/books/R100000002-I000002463690)』産業図書 (1995)

数理最適化に関する基本的なモデリングテクニックが記述されています．
本書は原著の第３版を元に翻訳されたものですが，[原著では新しく第５版](https://www.wiley.com/en-us/Model+Building+in+Mathematical+Programming%2C+5th+Edition-p-9781118443330)が出版されています．

- 池上敦子『[ナース・スケジューリング　問題把握とモデリング](https://www.kindaikagaku.co.jp/book_list/detail/9784764905580/)』近代科学社 (2018)

ナース・スケジューリングをテーマに書かれた書籍です．
現実の課題を意識しているだけでなく，アルゴリズム的背景にも踏み込んだ解説がなされていて，モデリングの考え方に新たな視点を与えてくれます．

- Nuorium Optimization Team「[定式化技法集](https://www.msi.co.jp/solution/nuopt/docs/techniques/index.html)」 (2022)

数理最適化の定式化に関する実践的な技法を体系的に整理したウェブサイトです．
$0$-$1$ 変数の扱い，定式化に共通する考え方，様々なモデリングテクニックや理論的背景など，実務で役立つ具体的な解説を豊富に掲載しています．

## 数理最適化の実装について

- 岩永二郎, 石原響太, 西村直樹, 田中一樹『[Pythonではじめる数理最適化　ケーススタディでモデリングのスキルを身につけよう（第2版）](https://www.ohmsha.co.jp/book/9784274231759/)』オーム社 (2024)

モデリング言語 PuLP を用いた最適化モデルの実装について，詳しく解説された書籍です．
現実の問題への応用が意識されていて，最適化を組み込んだアプリケーション開発についても触れられています．

- スティーブン・スキアナ（著）, 平田富夫（訳）『アルゴリズム設計マニュアル（原著第3版）（[上](https://www.maruzen-publishing.co.jp/book/b10122540.html)・[下](https://www.maruzen-publishing.co.jp/book/b10122541.html)）』丸善出版 (2024)

組合せ最適化を中心に，個別の問題に対するアルゴリズムなどが解説されています．
実践的な内容を扱っていて，入手可能なプログラム情報などについても記載されています．

- 本橋智光, 橋本秀太郎『[改訂新版　前処理大全　SQL／pandas／Polars実践テクニック](https://gihyo.jp/book/2024/978-4-297-14138-7)』技術評論社 (2024)

データを扱う際の前処理について，体系的に扱った本です．
機械学習の観点から書かれていますが，この本で述べられていることは数理最適化でも役立ちます．

## 数理最適化に関わる読み物

- 今野浩「[工学部ヒラノ教授](https://ebook.shinchosha.co.jp/writer/3867/)」シリーズ　新潮社 (2011〜2022)

数理最適化の専門家でもあった筆者による，「工学部の裏話」的な話を知ることのできる読み物です．
線形計画などの最適化に関する話題もあり，一昔前の最適化業界の雰囲気を知ることができます．

- ブライアン・クリスチャン, トム・グリフィス（著）, 田沢恭子（訳）『[アルゴリズム思考術　問題解決の最強ツール](https://www.hayakawa-online.co.jp/shop/g/g0000612207/)』早川書房 (2017)

数理最適化と関わりの深い様々なアルゴリズムを，豊かな歴史的背景とともに平易に解説しています．
その背景のもと，定量的な意思決定においてアルゴリズムが果たす役割や，具体的な指針を明快に紹介しています．

- ウィリアム・J・クック（著）, 松浦俊輔（訳）『[驚きの数学　巡回セールスマン問題](https://www.seidosha.co.jp/book/index.php?id=1934)』青土社 (2013)

本書では詳しく解説できなかった，巡回セールスマン問題の話題に触れることのできる本です．
歴史や応用，解法について入門者向けに紹介している他，数理最適化との関連も解説しています．
